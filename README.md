# รู้เรื่องหุ้น

โปรแกรมเดสก์ท็อปสำหรับวิเคราะห์หุ้นเบื้องต้น จัดการพอร์ต วิเคราะห์ความเสี่ยงของพอร์ต และบันทึกกำไร–ขาดทุนจากการซื้อขาย พัฒนาด้วย Python (Tkinter + SQLite)

โปรเจกต์ในรายวิชา ED251007 Computer Programming for Teachers
คณะศึกษาศาสตร์ มหาวิทยาลัยขอนแก่น

ผู้จัดทำ: นายวชิรวิทย์ ธีรเวชกุล (683050158-9)

## ความสามารถ

- สมัครสมาชิกและเข้าสู่ระบบ (เก็บรหัสผ่านแบบ hash PBKDF2-SHA256 พร้อม salt)
- วิเคราะห์หุ้น: ราคา ตัวชี้วัดพื้นฐาน (P/E, ROE, ROA, Net Margin) และคะแนนรวม
- จัดการพอร์ต: เพิ่ม แก้ไข ลบ ล้างหุ้น
- วิเคราะห์ความเสี่ยงพอร์ต: คะแนน 0–100 จาก 5 ปัจจัย, ข้อมูลตลาดจริง (beta, ความผันผวน, drawdown), Stress Test และแนวทางปรับสมดุล
- ปฏิทินบันทึกซื้อขายพร้อมคำนวณกำไร–ขาดทุนแบบ FIFO
- สรุปกำไร–ขาดทุนตามช่วงเวลา (USD และบาท)
